# v0.8.0: Hearthside Social Recreation

**Status:** Proposed release notes; local candidate only, publication blocked  
**Candidate label:** `v0.8.0-rc.1`  
**Required:** RimWorld 1.6 Core; no required DLC

## Player change note

- Central hearths now offer seated Social recreation at 1.2 times the ordinary
  rate while fueled, operational, and enabled as a gathering spot.
- Base hearth wood consumption is reduced from 6 to 3 per day. Rain still adds
  fuel consumption.
- Clearer descriptions explain existing oat processing, flax processing, and
  hearth recipes. Installation, upgrade, rollback, and bug-report guidance is
  expanded.

Ordinary social relaxation is unchanged and can still happen by the hearth at
its normal rate. Place seating near the hearth and keep its cooking position
clear. No new art, joy kind, ritual, mood aura, or Harmony dependency is included.

## Version and scope

The next minor version after v0.7.1 reflects an added gameplay activity under the
pre-1.0 versioning policy. This is a focused hearth improvement, not a declaration
that the Version 1.0 milestone is complete. The candidate label reserves no tag.
Rejected ringfort work is excluded; the existing Version 0.7 preview art remains.

## Installation and compatibility

Back up the colony save and previous package before testing. Replace the whole
manual mod folder rather than merging files, and enable only one Emerald Isle
copy. Existing hearth IDs and gather settings remain unchanged; the new job and
joy-giver definitions are additive. This candidate has compatibility level S0:
save survival and removal safety are not yet certified. Save/reload and rollback
of a disposable save containing the custom social job remain release checks.
Restore both the previous package and a pre-upgrade save if rollback is needed.
