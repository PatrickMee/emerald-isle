**Status:** Release candidate<br>
**Required:** RimWorld 1.6 Core<br>
**Officially supported DLC:** Royalty, Ideology, Biotech, Anomaly, Odyssey<br>
**Required DLC:** None

**Artifact:** `EmeraldIsle-v0.6.0.zip`<br>
**Candidate SHA-256:** `[recorded in the release checklist]`<br>
**Steam Workshop:** https://steamcommunity.com/sharedfiles/filedetails/?id=3763433723

## Summary

Version 0.6.0 adds vanilla-style x4 cooking bills for the existing Emerald Isle
oat foods. The bills reduce repetitive bill setup while preserving exact
per-unit ingredients, labor, output, nutrition, value, preservation, and food
behavior.

This is a focused one-feature release justified by the maintainer's accepted
in-game oat-bill check.

## Included Content

- All Version 0.5.1 content.
- `EI_CookOatPorridgeBulk`: 40 milled oats -> 4 oat porridges at 480 work.
- `EI_CookOatFlatbreadBulk`: 40 milled oats -> 4 oat flatbreads at 1680 work.
- Both bills are available at the Campfire, central hearth, Fueled Stove, and
  Electric Stove.
- English label, description, and job-string localization for both bills.

The release adds no new food items, bulk milling, extra batch sizes, efficiency
discounts, art, C#, Harmony, custom UI, research, settings, or framework work.

## Installation and Upgrade

Subscribe on the Steam Workshop for automatic installation, or manually replace
the existing `EmeraldIsle` folder with the exact release package. Do not merge
folders or install both versions side by side.

Adding this release to an existing save is additive and introduces no custom
serialized state or migration. Back up important saves before changing any mod
list.

## Compatibility and Intended Behavior

- RimWorld 1.6 Core remains required; no DLC is required.
- Existing single oat recipes and all oat-food item stats remain unchanged.
- x4 bills use vanilla target-count and product-handling behavior, including
  normal bill overproduction semantics.
- The public definition IDs and localization keys are additive and stable.

## Verification

The oats change passed repository XML, package, release-safety, texture-path,
runtime-contract, unit-test, and GitHub Actions validation. Patrick Mee then
confirmed in-game that the x4 oat bills appear at the intended campsite/Campfire,
central hearth, and stove stations and considered the change good to go.

The exact candidate digest, tagged-main archive, GitHub publication, Steam
staging, and independent subscriber verification are recorded in the
[Version 0.6.0 release checklist](v0.6.0-release-checklist.md).
