## Summary

Version 0.6.1 is a backward-compatible point release adding one bulk cooking
bill for the existing farmhouse cheese item. It builds on the v0.6.0 oat bulk
cooking baseline and adds no new item, save state, code, or dependency.

## Included Content

- All Version 0.6.0 oat bulk cooking content.
- `EI_MakeFarmhouseCheeseBulk`: 2.40 Milk -> 4 farmhouse cheeses at 2400 work.
- The bulk cheese bill is available at the central hearth, Fueled Stove, and
  Electric Stove; Campfire remains excluded.
- English label, description, and job-string localization for the bulk bill.

The release preserves `EI_MakeFarmhouseCheese`, `EI_FarmhouseCheese`, all
existing food stats and IDs, and the established cheese ingredient filters.

## Installation and Upgrade

Subscribe on the Steam Workshop for automatic installation, or manually replace
the existing `EmeraldIsle` folder with the exact release package. Do not merge
folders or install both versions side by side.

Adding this release to an existing save is additive and introduces no custom
serialized state or migration. Back up important saves before changing any mod
list.
