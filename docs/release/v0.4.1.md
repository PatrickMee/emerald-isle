# v0.4.1: Pasture and Larder

**Steam publication date:** 2026-08-01<br>
**Required:** RimWorld 1.6 Core<br>
**Required DLC:** None<br>
**Steam Workshop:** https://steamcommunity.com/sharedfiles/filedetails/?id=3763433723

## Summary

Pasture and Larder adds Kerry dairy cattle and farmhouse cheese. The published
package also contains the accepted Version 0.3.1 flax-yield and hand-quern
Crafting-experience tuning. No public definition was renamed or removed.

## Added

- Small, cold-hardy Kerry cattle that eat less and yield less milk per animal
  than a vanilla cow, with modestly better milk/feed efficiency and more
  animal-handling work for the same output.
- Farmhouse cheese made from 12 units of Core Milk at the central hearth or a
  vanilla fueled/electric stove. One cheese provides 0.50 nutrition and keeps
  for 35 unrefrigerated days.
- Original directional cattle, desiccated-carcass, cheese, and Workshop-preview
  artwork with recorded provenance.

## Included Balance Fixes

- Flax harvest yield is 9.
- `EI_MillOats` has `workSkillLearnFactor` 0.5.

## Compatibility

The release is additive and backward-compatible with existing Emerald Isle
saves. It requires RimWorld 1.6 Core and no DLC. Removing the mod from a save
containing its definitions can cause ordinary missing-definition warnings and
content loss.

## Publication Verification

The merged source stages 101 runtime files totaling 1,743,258 bytes. Steam item
`3763433723` reported public content manifest `6390032348413319287` with the
same 1,743,258-byte total after upload. A separate subscribed client initially
retained an older Workshop manifest; unsubscribe/resubscribe refreshed it and
the corrected quern value appeared in the installed XML.

The release discrepancy was caused by publishing an open feature branch that
predated accepted main-branch balance fixes. Version 0.4 content and both fixes
are now reconciled on `main`. Future releases use the exact-artifact workflow in
`docs/release/release-strategy.md`.

## Rollback

The prior GitHub-tagged release is `v0.3.1`. Back up important saves before
changing any mod list.
