# v0.5.1: Wolfhound Presentation Update

**Status:** Release candidate<br>
**Required:** RimWorld 1.6 Core<br>
**Officially supported DLC:** Royalty, Ideology, Biotech, Anomaly, Odyssey<br>
**Required DLC:** None

**Artifact:** `EmeraldIsle-v0.5.1.zip`<br>
**Candidate SHA-256:** `81ff4b028eb0b95521d34cc6f54ea1cab63f2d9281cd6929a0add8a4168b1715`<br>
**Steam Workshop:** https://steamcommunity.com/sharedfiles/filedetails/?id=3763433723

## Summary

Version 0.5.1 is a presentation and release-tooling patch for **The Wolfhound**.
It replaces the older Pasture and Larder Workshop preview with the approved
Version 0.5 banner and prevents the local Workshop staging backup from appearing
to RimWorld as a duplicate Emerald Isle installation.

The gameplay package otherwise preserves Version 0.5.0 behavior and stable
identifiers without balance, save-data, or compatibility changes.

## Changes

- Added the approved 1280x720 Version 0.5 Workshop preview featuring the
  rough-coated wolfhound beside the colonist in the household yard.
- Preserved the established cottage, dry-stone walls, hearth, crops,
  cheese-making, and Kerry cattle in the preview.
- Moved the staging rollback package from `Mods/EmeraldIsle.previous` to
  `ModStagingBackups/EmeraldIsle.previous`, outside RimWorld's mod scan path.
- Added regression coverage proving the staging process leaves only the active
  Emerald Isle package inside `Mods`.

## Installation and Upgrade

Subscribe on the Steam Workshop for automatic installation. Manual installs
replace the existing `EmeraldIsle` folder with the package from the release ZIP;
do not merge folders or install both versions side by side.

Upgrading from v0.5.0 requires no migration. The patch changes no gameplay
definition, stable ID, dependency, or serialized state. Back up important saves
before changing any mod list.

## Compatibility and Known Issues

RimWorld 1.6 Core remains required and no DLC is required. Royalty, Ideology,
Biotech, Anomaly, and Odyssey remain supported. Odyssey continues to add Attack
Target training to the wolfhound without adding Comfort.

No blocker or critical gameplay defect is known. The prior duplicate-package
warning was caused by a local staging backup inside `Mods`, not by the published
wolfhound definitions. The corrected staging tool retains a recoverable backup
outside RimWorld's scan path.
