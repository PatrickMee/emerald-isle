# v0.6.3: Bulk Oat Milling

**Status:** Release candidate<br>
**Required:** RimWorld 1.6 Core<br>
**Officially supported DLC:** Royalty, Ideology, Biotech, Anomaly, Odyssey<br>
**Required DLC:** None

**Artifact:** `EmeraldIsle-v0.6.3.zip`<br>
**Steam Workshop:** https://steamcommunity.com/sharedfiles/filedetails/?id=3763433723

## Summary

Version 0.6.3 is a focused, backward-compatible patch that adds a vanilla-style
x4 hand-quern bill for the existing oat-processing chain. It reduces repetitive
production work without changing per-unit labor, output, item stats, or food
behavior.

## Included Content

- All Version 0.6.2 content.
- `EI_MillOatsBulk`: 40 raw oats -> 40 milled oats at 720 work.
- The bulk bill is available only at `EI_HandQuern` and uses the same Crafting
  labor, effect, sound, and 0.5 learning factor as the existing milling bill.
- The original `EI_MillOats` bill and all existing oat-food definitions remain
  unchanged.

## Installation and Upgrade

Subscribe on the Steam Workshop for automatic installation, or manually replace
the existing `EmeraldIsle` folder with the exact release package. Do not merge
folders or install both versions side by side.

Adding this release to an existing save is additive and introduces no custom
serialized state or migration. Back up important saves before changing any mod
list.

## Verification

The bulk-milling change passed XML, package, release-safety, texture-path,
runtime-contract, unit-test, and CI validation. Patrick Mee confirmed the
complete hand-quern path in-game on 2026-08-22: the x4 bill appears, accepts 40
raw oats, and produces 40 milled oats with normal bill behavior.

The exact candidate digest, tagged-main archive, GitHub publication, Steam
staging, and independent subscriber verification are recorded in the
[Version 0.6.3 release checklist](v0.6.3-release-checklist.md).
