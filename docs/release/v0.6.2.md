# v0.6.2: Linen Core Recipe Compatibility

**Status:** Release candidate<br>
**Required:** RimWorld 1.6 Core<br>
**Officially supported DLC:** Royalty, Ideology, Biotech, Anomaly, Odyssey<br>
**Required DLC:** None

**Artifact:** `EmeraldIsle-v0.6.2.zip`<br>
**Steam Workshop:** https://steamcommunity.com/sharedfiles/filedetails/?id=3763433723

## Summary

Version 0.6.2 is a backward-compatible point release that adds linen
alternatives to five Core recipes without changing the original Cloth bills or
the vanilla output items.

## Included Content

- Linen alternative for the vanilla flak vest recipe: 30 linen.
- Linen alternative for the vanilla flak pants recipe: 30 linen.
- Linen alternative for the vanilla flak jacket recipe: 50 linen.
- Linen alternative for industrial medicine: 3 linen plus the vanilla
  herbal-medicine and neutroamine costs.
- Linen alternative for Molotov cocktails: 25 linen plus the vanilla
  chemfuel cost.
- Existing vanilla Cloth recipes, item stats, work, research, skills, benches,
  quality behavior, and effects remain unchanged.

## Installation and Upgrade

Subscribe on the Steam Workshop for automatic installation, or manually replace
the existing `EmeraldIsle` folder with the exact release package. Do not merge
folders or install both versions side by side.

Adding this release to an existing save is additive and introduces no custom
serialized state or migration. Back up important saves before changing any mod
list.
