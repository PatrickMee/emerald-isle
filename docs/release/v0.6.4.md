# v0.6.4: Oat Flatbread Food Priority

**Status:** Release candidate; human gameplay verification passed<br>
**Required:** RimWorld 1.6 Core<br>
**Officially supported DLC:** Royalty, Ideology, Biotech, Anomaly, Odyssey<br>
**Required DLC:** None

**Artifact:** `EmeraldIsle-v0.6.4.zip`<br>
**Steam Workshop:** https://steamcommunity.com/sharedfiles/filedetails/?id=3763433723

## Summary

Version 0.6.4 is a focused, backward-compatible balance patch for oat
flatbread. It gives flatbread the vanilla pemmican-style humanlike food-priority
offset of `6`, so it serves as a reserve and short-travel food without competing
with fresh meals and oat porridge when both are suitable and accessible.

## Included Content

- `EI_OatFlatbread` explicitly declares
  `<optimalityOffsetHumanlikes>6</optimalityOffsetHumanlikes>`.
- `EI_OatPorridge` retains its inherited `MealBase` offset and fresh-food path.
- Nutrition, work, ingredients, shelf life, mass, market value, recipes, bills,
  defNames, localization keys, art, and save-visible contracts are unchanged.
- No C#, Harmony, new serialized state, or migration is included.

## Installation and Upgrade

Subscribe on the Steam Workshop for automatic installation, or manually replace
the existing `EmeraldIsle` folder with the exact release package. Do not merge
folders or install both versions side by side.

Adding this release to an existing save is compatible with existing flatbread
stacks and bills. Back up important saves before changing any mod list.

## Verification

XML, package staging, release-safety, runtime-contract, texture-path, and unit
validation passed. Patrick Mee confirmed the complete affected RimWorld 1.6
food-priority, fallback-eating, save/load, stats/recipe, and log-cleanliness
checks on 2026-08-23. The exact candidate digest, tagged-main archive, GitHub
publication, Steam staging, and independent subscriber verification are recorded
in the [Version 0.6.4 release checklist](v0.6.4-release-checklist.md).

The human verification covered:

1. When fresh simple meals/oat porridge and oat flatbread are both allowed and
   similarly accessible, colonists normally choose fresh food first.
2. Colonists still eat flatbread when it is the allowed, available suitable food.
3. Existing flatbread stacks and bills survive save/load.
4. Flatbread still shows 0.8 nutrition, 14-day shelf life, unchanged mass/value,
   and working x1/x4 recipes.
5. No new XML or log errors appear.
