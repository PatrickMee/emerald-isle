# v0.7.1: Version 0.7 Workshop Preview

**Status:** Release candidate; maintainer visual review passed<br>
**Required:** RimWorld 1.6 Core<br>
**Officially supported DLC:** Royalty, Ideology, Biotech, Anomaly, Odyssey<br>
**Required DLC:** None

**Artifact:** `EmeraldIsle-v0.7.1.zip`<br>
**Steam Workshop:** https://steamcommunity.com/sharedfiles/filedetails/?id=3763433723

## Summary

Version 0.7.1 replaces the older Version 0.5 Workshop preview with the approved
Version 0.7 **Hearth & Larder** banner. It is a presentation-only patch; gameplay
is identical to v0.7.0.

## Included Content

- `About/Preview.png` now shows the established holding centered on the improved
  central hearth, household provisioning, Kerry cattle, and wolfhound.
- The exact banner text is `EMERALD ISLE`, `VERSION 0.7`, and `HEARTH & LARDER`.
- The runtime export is a 1280x720 indexed PNG, remains below Steam's one-megabyte
  preview limit, and retains the stable Workshop item and metadata paths.
- The Steam Workshop listing input now describes the complete Version 0.7 content
  and provides a focused v0.7.1 change note.
- Gameplay definitions, recipes, balance, public IDs, saves, localization, and
  runtime behavior are unchanged from v0.7.0.

## Installation and Upgrade

Subscribe on the Steam Workshop for automatic installation, or manually replace
the existing `EmeraldIsle` folder with the exact release package. Do not merge
folders or install multiple Emerald Isle versions side by side.

Existing saves remain compatible because this patch changes only Workshop artwork
and listing documentation. Back up important saves before changing any mod list.
