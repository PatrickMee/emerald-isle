## Summary

The Wolfhound adds a fast domestic coursing and combat companion. It is easier
to acquire and maintain than wild fighters, but consumes more food and creates
more colony wealth than ordinary utility dogs. Its role is player-directed
Guard and Attack work rather than hauling, rescuing, hunting, patrolling, or
autonomous livestock protection.

This focused one-feature release is justified by the wolfhound's complete,
independent player role and the maintainer's completed gameplay and visual
acceptance matrix.

## Included Content

- All Version 0.4.1 content.
- `EI_Wolfhound`, using vanilla Intermediate trainability with Guard and Attack.
- Odyssey-only Attack Target support using the same conditional pattern as
  vanilla combat canines. Odyssey Comfort is not added.
- Uncommon fighter-animal trader availability, with no ordinary wild-biome,
  ecosystem, scenario, or common starting-pet entry.
- A speed-led combat profile with 5.4 movement speed, combat power 88, ordinary
  large-dog health, 0.60 base hunger, market value 380, slow maturity, short
  lifespan, and small litters.
- Original rough-coated wolfhound artwork for required life stages, directions,
  and the desiccated state, with repository-recorded provenance.

The release adds no C#, Harmony patch, custom AI, UI, save state, research,
faction, event, quest, animal product, or pack-animal behavior.

## Installation

Subscribe on the Steam Workshop for automatic installation, or install manually:

1. Copy the staged `EmeraldIsle` folder into RimWorld's local `Mods` directory.
2. Confirm the resulting path contains `EmeraldIsle/About/About.xml` rather than
   an additional nested `EmeraldIsle` folder.
3. Enable **Emerald Isle** after **Core** and restart when prompted.

The separate Emerald Isle Developer Tools package is local-only and must never
be included in a public release.

## Upgrade and Existing Saves

Adding Version 0.5.0 to an existing Emerald Isle save is additive and requires no
custom migration. Existing colonies can acquire wolfhounds through supported
animal traders after upgrading.

Back up important saves before changing any mod list. Rolling back to Version
0.4.1 while a save contains wolfhounds can produce ordinary missing-definition
warnings and remove those animals. Remove or sell wolfhounds before rollback
where practical.

## Compatibility and Intended Behavior

- RimWorld 1.6 Core is required; no DLC is required.
- Core provides Tameness, Obedience, Guard, and Attack as appropriate. Rescue and
  Haul remain unavailable.
- Odyssey adds Attack Target only. It does not add Comfort.
- The wolfhound is not a pack animal and does not carry caravan cargo.
- No supported configuration adds autonomous patrol, hunting, herd protection,
  ordinary wild spawning, or common starting-pet availability.
- Stable `EI_Wolfhound` identifiers and localization keys are additive save
  contracts.
