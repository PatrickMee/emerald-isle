## Summary

This patch makes flax production more worthwhile and rewards hand-quern milling
with modest Crafting experience. It changes no public IDs, recipes, apparel,
assets, localization, dependencies, or serialized state.

## Balance Changes

- Flax plants yield 9 raw flax instead of 8. At their unchanged 6-day growth
  time, this raises ideal textile output from about 6.7% to 20% above cotton per
  field-day before processing. Flax remains ground-only and still requires the
  existing raw-flax-to-linen labor.
- Hand-quern milling grants Crafting experience at half the normal recipe rate,
  rewarding the processing step without making it an efficient training method.

## Installation

Subscribe on the Steam Workshop for automatic installation, or install manually:

1. Copy the staged `EmeraldIsle` folder into RimWorld's local `Mods` directory.
2. Confirm the resulting path contains `EmeraldIsle/About/About.xml` rather than
   an additional nested `EmeraldIsle` folder.
3. Enable **Emerald Isle** after **Core** and restart when prompted.

The separate Emerald Isle Developer Tools package is local-only and must never be
included in a public release.

## Upgrade and Compatibility

Version 0.3.1 is a backward-compatible balance patch for Version 0.3 saves.
Existing flax plants use the revised harvest yield when harvested. The quern XP
change adds no state. RimWorld 1.6 Core remains required; supported DLC add no
patch-specific behavior.

Back up important saves before changing any mod list. Removing Emerald Isle from
a save containing its content can produce ordinary missing-definition warnings
and content loss.
