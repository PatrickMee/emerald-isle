## Art Brief

The Version 0.5 preview preserves the established wide isometric holding, quiet
left-side title field, dry-stone construction, thatched cottage, central hearth,
cheese-making, crops, and Kerry cattle. A rough-coated iron-grey wolfhound now
stands beside the colonist in the open household yard. It is deliberately outside
the cattle pen and reads as a domestic companion rather than an autonomous
livestock guardian.

The wolfhound uses a lean torso, deep chest, tucked waist, raised shoulder line,
long bearded muzzle, folded ears, and tapered tail to remain recognizable at the
400x225 Steam thumbnail scale. The exact release typography reads `EMERALD ISLE`,
`VERSION 0.5`, and `THE WOLFHOUND`.

## Provenance and License

OpenAI's built-in image-generation tool produced an original edit using the
project-owned Version 0.4 preview as the scene and composition reference and the
accepted AN-01 east-facing sprite as the wolfhound identity reference. The first
pass added the hound beside the colonist and cleared the obsolete subtitle. A
second constrained pass added the exact Version 0.5 typography. No RimWorld
screenshot, Core-art pixel, third-party image, or unsupported asset was copied or
composited into the preview.

Codex resized the selected generated source to 1280x720 and palette-optimized the
PNG below Steam Workshop's one-megabyte preview ceiling. Generated sources and
thumbnail checks remain ignored production intermediates rather than runtime
dependencies or committed source art. The preview is governed by
[`CREATIVE_ASSETS_LICENSE.md`](../../../CREATIVE_ASSETS_LICENSE.md).
